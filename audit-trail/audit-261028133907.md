# Clue & Rekomendasi: Pemantauan Background Worker Global

## 1. Jawaban Status Pindah Halaman
- **Pindah halaman TIDAK merusak proses di server**: Worker berjalan di thread background Python (`worker.py`). Data tetap divalidasi dan disimpan ke DB.
- **Masalah yang terjadi**: Polling UI hanya hidup di tab `upload.html`. Jika pindah halaman, browser berhenti memantau `task_id` sehingga notifikasi selesai/ditolak hilang dari layar.

---

## 2. Solusi Rekomendasi: Global Floating / Header Indicator

Gunakan kombinasi **endpoint status worker global** + **komponen UI di `base.html`** agar indikator aktif di halaman mana pun.

```
[Halaman Mana Pun] 
   └── base.html memuat global_worker.js
         └── Memeriksa status task aktif (via localStorage & endpoint /api/worker/active)
         └── Menampilkan badge berputar di header + floating toast di pojok saat selesai
```

---

## 3. Rencana Perubahan Kode

### A. [app.py](file:///c:/laragon/www/wilkerstat-checker/app.py)
Tambahkan endpoint untuk mengecek apakah ada task yang sedang berjalan di background:
```python
@app.route("/api/worker/active")
def api_worker_active():
    """Mengembalikan daftar task yang sedang queued atau processing."""
    conn = db.get_connection()
    rows = conn.execute("""
        SELECT id, filename, upload_type, status, ts
        FROM upload_log
        WHERE status IN ('pending', 'processing')
        ORDER BY id DESC
    """).fetchall()
    active_tasks = [dict(r) for r in rows]
    conn.close()
    return jsonify({"active": len(active_tasks) > 0, "tasks": active_tasks})
```

### C. [static/global_worker.js](file:///c:/laragon/www/wilkerstat-checker/static/global_worker.js) (File Baru)
Logika pemantau global:
1. Simpan daftar `task_id` aktif di `localStorage`.
2. Saat upload dimulai di `upload.js`, trigger pendaftaran task ke `localStorage`.
3. `global_worker.js` melakukan polling `/api/upload/status/<task_id>` secara periodik (setiap 2-3 detik) jika ada task aktif.
4. Update badge di navbar:
   - Jika ada proses: tampilkan animasi loading & nama file.
   - Jika selesai/gagal: munculkan toast di pojok kanan bawah ("✅ Validasi [file] selesai" / "❌ File ditolak") dan hapus dari `localStorage`.
   - Toast dapat diklik untuk mengarah ke `/history`.
