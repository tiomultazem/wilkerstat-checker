# Rencana Implementasi & Blueprint Teknis: WilkerStat Checker

Dokumen ini memuat detail rencana perbaikan sesuai keputusan:
1. **Target SLS**: Menggunakan target kolektif riil master pada ringkasan, tanpa pengalian jumlah petugas.
2. **Re-upload Master**: Otomatis *clean replace* (menghapus data master lama) dalam satu transaksi database.
3. **Layout GIS**: Tampilan *fullscreen* tanpa scroll vertikal halaman dengan sidebar mengambang dan kontrol peta kompak.

---

## 1. Perbaikan Target SLS & Kategori "(tanpa petugas)"

### A. Aturan Logika Target Poligon
1. **Ringkasan Total Target Header**:
   - Total Target pada ringkasan atas dikunci ke nilai riil `COUNT(*) FROM master_shape` (misal 1.106).
   - Di [static/home.js](file:///c:/laragon/www/wilkerstat-checker/static/home.js), hentikan penjumlahan akumulatif `totalTarget += target` antar petugas jika master tanpa petugas.
2. **Target Petugas Individual**:
   - Jika kolom `petugas` di master **terisi**: Target per petugas = jumlah SLS master miliknya.
   - Jika kolom `petugas` di master **kosong**: Target masing-masing petugas ditampilkan terhadap target kolektif (contoh: `345 / 1106`, `318 / 1106`, `180 / 1106`).
3. **Kategori `(tanpa petugas)` Poligon**:
   - SLS yang belum diunggah oleh petugas mana pun dihitung dari:
     ```sql
     SELECT COUNT(*) FROM master_shape m
     WHERE m.idsubsls NOT IN (SELECT idsubsls FROM shape)
     ```
   - Ditampilkan sebagai bar tersendiri: `(Belum Diupload / Tanpa Petugas)` = $1.106 - 843 = 263$ SLS.

## 2. Mekanisme Re-upload Master & Reset Database Aman

### A. Solusi Kunci File SQLite di Windows
- Masalah crash terjadi saat berkas `.db` dihapus paksa lewat Windows Explorer saat proses Python memegang *file handle*.
- Solusi: Seluruh pembersihan dilakukan melalui query SQL aktif tanpa menghapus berkas dari disk.

### B. Clean Replace Otomatis Saat Upload Master
Di [app.py](file:///c:/laragon/www/wilkerstat-checker/app.py):
1. **Pada `_process_master_shape`**:
   Jalankan `conn.execute("DELETE FROM master_shape")` sebelum memasukkan rekaman GeoJSON/Excel master baru.
2. **Pada `_process_master_dot`**:
   Jalankan `conn.execute("DELETE FROM master_dot")` sebelum memasukkan rekaman titik master baru.
3. Setelah master shape diperbarui, jalankan `conn.commit()` dan picu penyesuaian ulang target otomatis.

### C. Endpoint & Tombol Reset Database
Tambahkan endpoint `POST /api/admin/reset-data` di [app.py](file:///c:/laragon/www/wilkerstat-checker/app.py):
- Parameter opsi: `target: "all" | "shape" | "dot" | "master"`
- Membersihkan tabel terkait (`shape`, `dot`, `issue`, `petugas_stats`, `upload_log`) secara aman dan instan tanpa perlu restart server.
