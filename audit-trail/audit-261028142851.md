# Rancangan Perbaikan: Target SLS, Layout Fullscreen GIS, & Reset Master

## 1. Perbaikan Target SLS & Kategori "(tanpa petugas)"

### A. Masalah Saat Ini
1. **Target Membengkak (3.318 vs 1.106)**:
   Di [app.py](file:///c:/laragon/www/wilkerstat-checker/app.py) dan [home.js](file:///c:/laragon/www/wilkerstat-checker/static/home.js), jika master tidak memiliki kolom petugas, setiap petugas diberi target 1.106. Frontend menjumlahkan target individual $(1.106 \times 3 = 3.318)$, sehingga total target menjadi kelipatan jumlah petugas.
2. **(tanpa petugas) Poligon Nol**:
   Saat ini belum ada penghitungan SLS master yang belum diupload oleh petugas mana pun.

### B. Rencana Perbaikan
1. **Logika Target**:
   - Jika kolom petugas di master ada: Target per petugas = jumlah SLS master milik petugas tersebut.
   - Jika kolom petugas di master kosong/tidak ada:
     - Total target di ringkasan dikunci ke total master riil (1.106).
     - Target individual petugas dibagi rata ($\text{Total Master} / N$ petugas) atau disajikan sebagai capaian dari target kolektif.
2. **Kategori `(tanpa petugas)` Poligon**:
   - Dihitung dari:
     ```sql
     SELECT COUNT(*) FROM master_shape m
     WHERE m.idsubsls NOT IN (SELECT idsubsls FROM shape)
     ```
   - Ditampilkan sebagai bar: `(Belum Diupload / Tanpa Petugas)` = $1.106 - 843 = 263$ SLS.

## 3. Penanganan Re-upload Master & Reset Database Aman

### A. Penyebab Masalah
1. **Kunci Berkas SQLite di Windows**: Menghapus berkas `wilkerstat.db` saat aplikasi Python masih berjalan menyebabkan Windows mengunci file (`WinError 32`), memutus koneksi pool, dan membuat server gagal koneksi sampai aplikasi direstart.
2. **Re-upload Tidak Menghapus Data Lama**: `_process_master_shape` menggunakan `INSERT OR REPLACE`, sehingga rekaman lama yang dihapus dari master baru tetap tertinggal di tabel.

### B. Rencana Perbaikan
1. **Truncate Bersih Saat Upload Master**:
   Tambahkan `DELETE FROM master_shape` (dalam satu transaksi database) sebelum memasukkan data master baru, sehingga target langsung sinkron dengan berkas terbaru.
2. **Fitur Reset / Kosongkan Data dari Web**:
   Tambahkan tombol "Reset Database" pada antarmuka (dengan dialog konfirmasi), yang mengeksekusi penghapusan isi tabel secara aman tanpa menghapus berkas SQLite fisik dari disk.
