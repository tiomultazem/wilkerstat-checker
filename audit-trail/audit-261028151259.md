# Analisis & Rencana Perbaikan: Perataan Dropzone Upload & Dukungan Drag and Drop

## 1. Masalah yang Teridentifikasi pada Halaman Upload ([templates/upload.html](file:///c:/laragon/www/wilkerstat-checker/templates/upload.html))

1. **Kotak Patah-patah (File Input) Tidak Sejajar Horizontal**:
   - Masing-masing kartu upload (`.upload-card`) memiliki panjang teks deskripsi (`<p>`) yang berbeda-beda:
     - Kartu 1: 1 baris
     - Kartu 2: 3 baris
     - Kartu 3: 2 baris
   - Karena kontainer kartu tidak mengatur pemuaian vertikal fleksibel (*flex expansion*), elemen `<form>` dan kotak input file berada pada ketinggian yang berbeda-beda di ketiga kartu.
2. **Tidak Ada Interaksi Drag and Drop yang Intuitif**:
   - Elemen `<input type="file">` standar hanya memiliki gaya `border: 2px dashed var(--border)`.
   - Tidak ada penanganan event visual (`dragover`, `dragleave`, `drop`) maupun teks interaktif untuk mempermudah pengguna menarik dan melepaskan berkas langsung ke dalam kotak.

---

## 2. Rencana Solusi & Perbaikan

### A. Perataan Garis Dasar Kotak Upload (CSS Flexbox)
Di [static/style.css](file:///c:/laragon/www/wilkerstat-checker/static/style.css):
1. Ubah `.upload-card` menjadi Flexbox vertikal:
   ```css
   .upload-card {
       display: flex;
       flex-direction: column;
       height: 100%;
   }
   ```
2. Berikan `flex: 1;` pada elemen paragraf keterangan `.upload-card p`:
   - Paragraf otomatis mengisi sisa ruang kosong di atasnya.
   - Elemen `<form>` beserta kotak dropzone akan selalu terdorong dan terkunci pada posisi dasar yang sama persis di ketiga kartu secara horizontal.

### B. Komponen Dropzone dengan Fitur Drag and Drop
1. **Restrukturisasi Tampilan di [templates/upload.html](file:///c:/laragon/www/wilkerstat-checker/templates/upload.html)**:
   Ganti input standar dengan pembungkus `.drop-zone`:
   ```html
   <div class="drop-zone" id="dropZoneMasterShape">
       <div class="drop-zone-icon">📁</div>
       <div class="drop-zone-label">Tarik & lepas file ke sini atau <span>pilih file</span></div>
       <div class="drop-zone-filename" style="display:none;"></div>
       <input type="file" name="file" accept=".csv,.xlsx,.xls,.geojson,.json" required>
   </div>
   ```
2. **Styling di [static/style.css](file:///c:/laragon/www/wilkerstat-checker/static/style.css)**:
   - Kotak putus-putus berukuran tinggi tetap (`min-height: 110px`), teks rata tengah, kursor pointer.
   - Efek visual `.drop-zone.dragover`: latar belakang berubah biru muda (`#eff6ff`), border berubah warna primer (`#2563eb`), dan sedikit membesar (*scale 1.02*).
3. **Logika JavaScript di [static/upload.js](file:///c:/laragon/www/wilkerstat-checker/static/upload.js)**:
   - Tangani event `dragover`, `dragenter`, `dragleave`, dan `drop`.
   - Saat file di-drop, isi `input.files = e.dataTransfer.files`, perbarui label nama file terpilih, dan siapkan tombol upload.
