# Clue: Referensi Titik Terhadap Poligon

## 1. Lokasi Kode Saat Ini yang Mereferensikan Titik ke Poligon Upload (`shape`)

### A. [validate_dot.py](file:///c:/laragon/www/wilkerstat-checker/validate_dot.py)
1. **Query Geometri Poligon Acuan** (Baris 97–106 & Baris 328–337):
   ```python
   shape_rows = conn.execute("SELECT idsubsls, geom_wkb, petugas FROM shape WHERE geom_wkb IS NOT NULL").fetchall()
   ```
   *Masalah*: Hanya mengambil poligon dari tabel `shape` (hasil upload petugas).

2. **Penentuan Status Titik** (Baris 136–160 & Baris 350–375):
   ```python
   elif idsub_origin in shape_map:
       poly_geom = shape_map[idsub_origin]
       inside, dist = check_point_in_polygon(geom, poly_geom)
       ...
   elif idsub_origin in master_ids:
       status = "MENUNGGU_SHAPE"
   ```
   *Masalah*: Jika SLS belum diupload ke `shape`, status titik menjadi `MENUNGGU_SHAPE` dan tidak dihitung posisi inside/offside-nya.

3. **Agregasi Statistik Petugas** (Baris 393–402):
   ```python
   SELECT s.petugas, COUNT(d.id) as total,
       SUM(CASE WHEN d.status='INSIDE'  THEN 1 ELSE 0 END) as inside_count,
       SUM(CASE WHEN d.flag_repair=1    THEN 1 ELSE 0 END) as offside,
       SUM(CASE WHEN d.flag_position=1  THEN 1 ELSE 0 END) as moved
   FROM dot d
   LEFT JOIN shape s ON d.idsubsls_origin = s.idsubsls
   WHERE s.petugas IS NOT NULL
   GROUP BY s.petugas
   ```
   *Masalah*: Titik dikelompokkan ke petugas melalui `shape.petugas`. Jika poligon belum diupload, `s.petugas` bernilai `NULL` sehingga titik masuk ke `(tanpa petugas)`.

### B. [app.py](file:///c:/laragon/www/wilkerstat-checker/app.py)
1. **Penghitungan Target Titik per Petugas** (Baris 178–196):
   ```python
   SELECT s.petugas, COUNT(d.id) as c
   FROM dot d
   JOIN shape s ON d.idsubsls_origin = s.idsubsls
   GROUP BY s.petugas
   ```
   *Masalah*: Target titik dikaitkan ke petugas berdasarkan poligon `shape` yang sudah terupload, bukan dari `master_shape`.

## 2. Yang Harus Dilakukan Jika Titik Direferensikan Terhadap SLS Master

1. **Pastikan `master_shape` Memiliki Geometri & Atribut Petugas**:
   - Master GeoJSON harus menyimpan `geom_wkb` dan `petugas` ke dalam tabel `master_shape`.

2. **Ubah Sumber Poligon di [validate_dot.py](file:///c:/laragon/www/wilkerstat-checker/validate_dot.py)**:
   - Ambil poligon dari `master_shape` (atau fallback jika ingin prioritas master/petugas):
     ```python
     shape_rows = conn.execute("SELECT idsubsls, geom_wkb, petugas FROM master_shape WHERE geom_wkb IS NOT NULL").fetchall()
     ```
   - Hapus status `MENUNGGU_SHAPE` untuk SLS yang ada di `master_shape` karena geometrinya langsung diuji terhadap poligon master.

3. **Ubah Relasi Petugas di Agregasi Statistik**:
   - Di `_update_dot_petugas_stats`, ganti `JOIN shape s` menjadi `JOIN master_shape m ON d.idsubsls_origin = m.idsubsls`.
   - Hubungkan kelompok progres berdasarkan petugas di `master_shape`.

4. **Ubah Query Target di [app.py](file:///c:/laragon/www/wilkerstat-checker/app.py)**:
   - Ganti `JOIN shape` pada query target titik dengan `JOIN master_shape`.
